---
title: "Géocoder un lieu"
description: Résoudre un nom de lieu français (commune, adresse, gare, POI) en coordonnées GPS avec un score de confiance.
---

Imoria s'appuie sur la BAN (Base Adresse Nationale) et les bases IGN pour résoudre un nom de lieu en coordonnées. C'est l'étape implicite de la plupart des analyses géographiques. Mais elle peut aussi servir explicitement quand un cadre précis est nécessaire.

<Info>
  Le géocodage est appelé automatiquement quand le prompt mentionne un lieu en mots ("autour de la gare de Metz"). L'invoquer explicitement sert surtout à vérifier qu'Imoria a la bonne interprétation.
</Info>

## Exemple de prompt

```text title="Dans le client IA"
Trouve les coordonnées exactes du centre-ville de Verdun.
```

## Ce qu'Imoria renvoie

| Champ         | Signification                                                   |
| ------------- | --------------------------------------------------------------- |
| `query`       | La requête initiale                                             |
| `results`     | Liste des candidats classés par confiance                       |
| `lat` / `lng` | Coordonnées GPS                                                 |
| `confidence`  | Score de 0 à 1 sur la qualité du match                          |
| `type`        | Nature du lieu (`commune`, `address`, `poi`, `intersection`...) |
| `label`       | Libellé canonique retourné par la source                        |
| `source`      | `BAN`, `IGN`, ou base interne POI                               |

Quand plusieurs candidats sortent (ambiguïté), Imoria les présente tous. Le contexte du prompt permet généralement de trancher.

**Exemple de réponse réelle :**

```text title="Réponse Imoria"
Géocodage — « Saint-Avold »  (3 candidats)

#1   Saint-Avold (57500)
     lat 49.1066, lng 6.7053
     type commune · confiance 0.98 · source BAN

#2   Saint-Avold gare SNCF
     lat 49.1003, lng 6.7099
     type poi · confiance 0.92 · source IGN

#3   Saint-Avold (place du marché)
     lat 49.1071, lng 6.7048
     type address · confiance 0.74 · source BAN
```

## Limites

- Les **adresses anciennes ou récemment renommées** peuvent ne pas figurer dans la BAN. Dans ce cas, Imoria propose le candidat le plus proche avec un score de confiance dégradé.
- Les **POI très spécifiques** (petits commerces, professions libérales) ne sont pas tous indexés. Préférer un type de POI codifié dans la base INSEE BPE pour les recherches systématiques.
