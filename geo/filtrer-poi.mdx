---
title: "Filtrer par POI"
description: Restreindre une recherche d'annonces aux biens proches d'un type d'équipement. École, gare, commerce, médecin.
---

Imoria s'appuie sur la base **BPE** (Base Permanente des Équipements) de l'INSEE, qui recense environ 229 catégories de points d'intérêt. Éducation, transport, commerce, santé, sport, services, tourisme. Tout filtre de recherche peut combiner un critère "proche d'un POI de type X dans un rayon Y".

<Info>
  La base BPE est mise à jour annuellement par l'INSEE. Les changements rapides (ouverture de commerce, déménagement) peuvent ne pas être reflétés immédiatement.
</Info>

## Exemple de prompt

```text title="Dans le client IA"
Trouve les T3 à Nancy sous 220 000 €, à moins de 500 m d'une école primaire.
```

## Ce qu'Imoria fait derrière

1. Le client IA traduit "école primaire" en code POI INSEE (`C101` par exemple).
2. Imoria géocode les écoles primaires dans la zone.
3. La recherche d'annonces filtre celles dont le point géographique est dans le rayon demandé d'au moins une école.
4. Les résultats incluent la distance à l'école la plus proche.

**Exemple de réponse réelle :**

## Catégories de POI courantes

Quelques exemples utiles pour un usage immo. Pour la liste complète, demander à Imoria "liste les catégories de POI disponibles". Il appelle `list_poi_categories` et renvoie les ~229 codes.

| Domaine             | Exemples                                                     |
| ------------------- | ------------------------------------------------------------ |
| **Éducation**       | Écoles maternelles, primaires, collèges, lycées, universités |
| **Transport**       | Gares SNCF, métros, arrêts de tramway, parkings publics      |
| **Commerce**        | Supermarchés, boulangeries, pharmacies, marchés              |
| **Santé**           | Médecins généralistes, dentistes, hôpitaux, cliniques        |
| **Services**        | Postes, mairies, banques, garderies                          |
| **Sport / loisirs** | Piscines, salles de sport, tennis, terrains de foot          |
| **Tourisme**        | Musées, cinémas, parcs, monuments                            |

## Limites

<Card href="/ressources/limites-et-couvertures#adresses-masquees-sur-les-annonces" icon="link" horizontal>
  Voir : adresses-masquees-sur-les-annonces
</Card>

- Comme une partie des annonces a une adresse masquée, le filtre "à moins de X mètres d'un POI" est **approximatif en zone dense**. En zone rurale ou en petite commune, l'imprécision est minime.
- La BPE est annuelle. Les **changements récents** (nouveau commerce, fermeture d'école) peuvent ne pas être pris en compte.
- Pour un POI très spécifique non listé dans la BPE, le mieux est de géocoder l'adresse exacte et d'utiliser un filtre `near` (lat/lng + rayon).

<Accordion title="Avancé. Outils MCP et paramètres">
Deux outils impliqués selon le besoin :

`list_poi_categories`. Sans paramètre, renvoie `[{ code, label, domain, count }]` pour les ~229 catégories BPE.

Filtre `nearPoi` (disponible sur `search_ads`, `search_ads_hybrid`, `search_ads_semantic`, `find_undervalued_ads`, `query_real_estate`) :

- `category`. Code BPE (ex. `C101` pour école primaire).
- `radiusMeters`. Rayon en mètres.

Plusieurs `nearPoi` peuvent être combinés (ET logique : à la fois proche d'une école ET d'un supermarché).
</Accordion>
