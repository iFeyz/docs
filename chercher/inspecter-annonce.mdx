---
title: "Inspecter une annonce"
description: Décortiquer une annonce précise — détails du bien, parcelle cadastrale, DPE le plus proche, comparables, contexte de marché.
---

Une fois une annonce repérée (via une recherche, ou en collant simplement son URL dans le chat), Imoria peut en faire un audit complet : caractéristiques du bien, contexte de marché, comparables, parcelle cadastrale, DPE.

<Info>
  Cette page est l'angle "**plonger dans un bien**". Pour une fourchette de valeur dédiée, voir [Estimer la valeur d'un bien](../evaluer/estimer-valeur) ; pour le contexte du quartier, [Étudier un quartier](../evaluer/etudier-quartier).
</Info>

## Exemple de prompt

```text title="Dans le client IA"
Voici une annonce, fais-en un audit complet : https://exemple.fr/annonce/1234567
```

Ou en référant à une annonce déjà dans la conversation :

```text title="Référence dans la conversation"
Plonge dans le détail de la troisième annonce de la liste.
```

## Ce qu'Imoria renvoie

Un dossier structuré sur l'annonce :

| Section                        | Contenu                                                                                                        |
| ------------------------------ | -------------------------------------------------------------------------------------------------------------- |
| **Identité**                   | Titre, prix demandé, type, surface, pièces, étage, DPE déclaré                                                 |
| **Localisation**               | Ville, département, parcelle cadastrale si l'adresse est suffisamment précise                                  |
| **DPE le plus proche**         | Note A à G du diagnostic le plus proche dans un rayon de 50 m (utile quand l'annonce n'a pas de DPE renseigné) |
| **Historique DVF**             | Mutations récentes sur la même parcelle ou des parcelles voisines (sauf Alsace-Moselle)                        |
| **Vendeur**                    | `PARTICULIER` ou `PRO`, sans informations personnelles                                                         |
| **Première vue / disparition** | Date d'apparition sur le catalogue Imoria, date de retrait si applicable                                       |
| **URL d'origine**              | Lien direct vers l'annonce du vendeur                                                                          |

**Exemple de réponse réelle :**

```text title="Réponse Imoria"
Inspection — Annonce ad_8c4f29...

Identité
  Titre              T2 lumineux 58 m² centre-ville Nancy
  Prix demandé       165 000 €  (2 845 €/m²)
  Type               Appartement T2 · 4 pièces · 58 m² · étage 3/5
  DPE                D (déclaré dans l'annonce)
  Vendeur            PARTICULIER

Localisation
  Adresse            Nancy 54000 (rue non précisée — adresse masquée)
  Département        54 (Meurthe-et-Moselle)
  Parcelle cadastrale  non liée (adresse trop floue)

DPE le plus proche
  Classe D · à 35 m · diagnostiqué 2024-09 · bâtiment voisin

Historique DVF (rayon 200 m)
  3 mutations 2024-2025
  Médiane 2 920 €/m² (n=3)
  Marge négo. typique secteur: -7%

Historique annonce
  Première vue       il y a 3 jours
  Statut             ACTIVE
  Variations prix    aucune depuis publication

URL d'origine        https://exemple.fr/annonce/1234567
```

## Limites

<Card href="/ressources/limites-et-couvertures#adresses-masquees-sur-les-annonces" icon="link" horizontal>
  Voir : adresses-masquees-sur-les-annonces
</Card>

- Quand l'adresse est masquée, la **liaison à une parcelle cadastrale précise** est impossible — Imoria reste alors à l'échelle de la commune.
- Les données déclaratives (surface, DPE, étage) proviennent du vendeur et ne sont pas vérifiées par Imoria.

<Accordion title="Avancé — outils MCP et paramètres">
Cette page utilise principalement `get_ad_by_id`, parfois combiné avec `estimate_ad_value`, `find_comparables` et `analyze_location` selon ce qui est demandé.

`get_ad_by_id` :

- `adId` (UUID) — identifiant de l'annonce dans Imoria.

Le client IA résout automatiquement une URL d'annonce en `adId` quand c'est nécessaire.
</Accordion>
