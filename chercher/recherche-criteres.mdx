title: "Recherche par critères"
description: Trouver des biens par critères stricts. Ville, surface, prix, DPE, type de vendeur, et plus encore.
---

C'est l'angle d'attaque classique : la cible est claire, un T2 à Nancy sous 180 k€, par exemple, et l'objectif est la liste exhaustive triée par prix ou par date.

<Info>
  Imoria combine sans limite les critères suivants : ville, département, fourchette de prix, surface, nombre de chambres, classe DPE, type de vendeur (particulier ou professionnel), zone custom (polygone), statut (annonce active ou disparue).
</Info>

## Exemple de prompt

```text title="Dans le client IA"
Trouve les appartements T2 à Nancy sous 180 000 €, classés du moins cher au plus cher. Ne garder que les ventes par particuliers, avec une note DPE de D ou mieux.
```

## Ce qu'Imoria renvoie

Une liste paginée des annonces qui matchent. Chaque ligne contient :

| Champ                   | Signification                                     |
| ----------------------- | ------------------------------------------------- |
| `titre`                 | Titre de l'annonce tel qu'affiché par le vendeur  |
| `prix demandé`          | Prix annoncé en euros                             |
| `surface`               | Surface habitable en m² (déclarée par le vendeur) |
| `pièces` / `chambres`   | Typologie de l'appartement                        |
| `ville` / `département` | Localisation administrative                       |
| `dpe`                   | Classe énergétique (A à G) si renseignée          |
| `sellerType`            | `PARTICULIER` ou `PRO`                            |
| `firstSeenAt`           | Date de la première fois où Imoria a vu l'annonce |
| `url`                   | Lien direct vers l'annonce d'origine              |

Par défaut, Imoria renvoie les 20 premiers résultats. Une demande de pagination ("les 50 suivants") suffit pour continuer.

**Exemple de réponse réelle :**

## Limites

- Les **adresses sont parfois masquées** : voir [Limites & couvertures](/ressources/limites-et-couvertures#adresses-masquees-sur-les-annonces).
- Les **descriptions des annonces sont rédigées par les vendeurs** : la qualité varie. Pour une recherche plus tolérante au flou, [la recherche sémantique](/chercher/recherche-semantique) est mieux adaptée.

<Accordion title="Avancé. Outil MCP et paramètres">
Cette page utilise principalement `search_ads`. Paramètres clés :

- `query`. Texte libre dans le titre ou la description
- `category` / `archetype`. Type de bien
- `minPrice` / `maxPrice`. Fourchette de prix
- `minSurfaceM2` / `maxSurfaceM2`. Fourchette de surface
- `minBedrooms` / `maxBedrooms`. Chambres
- `sellerType`. PARTICULIER` | `PRO`
- `department`. Code département (ex. `54`)
- `city`. Nom de ville
- `polygon`. Zone custom (GeoJSON)
- `energyRate`. DPE minimum
- `sort`. price_asc` | `price_desc` | `firstSeen_desc`
- `status`. ACTIVE` | `DISAPPEARED`
- `limit` / `offset`. Pagination

Détails complets : [Référence outils](/ressources/reference-outils).
</Accordion>
