## Profondeur de l'analyse

Les quatre outils se complètent et empilent leurs résultats. Un audit complet d'une annonce mobilise typiquement les quatre :

| Étape             | Outil               | Apport                            |
| ----------------- | ------------------- | --------------------------------- |
| 1. Cadrer         | Estimer la valeur   | Fourchette + verdict              |
| 2. Justifier      | Comparables         | Les biens utilisés pour le calcul |
| 3. Contextualiser | Étudier un quartier | DVF, POI, marge de négociation    |
| 4. Anticiper      | Comparer un marché  | Tendance 18 mois                  |

Le client IA enchaîne les outils dans une seule conversation, en transmettant le contexte d'un appel au suivant.
