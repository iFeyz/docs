Pour valider ou contester une estimation, le meilleur outil est la **liste des comparables**. Imoria renvoie les K biens les plus proches d'une annonce donnée, classés par similarité (géographique, surface, description).

<Info>
  Par défaut, Imoria renvoie 10 comparables. Le nombre est ajustable jusqu'à 50.
</Info>

## Exemple de prompt

```text title="Dans le client IA"
Donne-moi les 15 comparables les plus proches de cette annonce.
```

## Ce qu'Imoria renvoie

Une liste de biens classés par score de similarité. Chaque ligne contient :

| Champ                | Signification                                                                 |
| -------------------- | ----------------------------------------------------------------------------- |
| `prix demandé`       | Prix de l'annonce comparable                                                  |
| `surface` / `pièces` | Caractéristiques du comparable                                                |
| `distance`           | Distance géographique au bien d'origine, en mètres ou kilomètres              |
| `similarity`         | Score composite (typologie + surface + géo + description), 0 à 1              |
| `dpe`                | Classe énergétique si renseignée                                              |
| `firstSeenAt`        | Quand le comparable est apparu sur le catalogue                               |
| `status`             | `ACTIVE` ou `DISAPPEARED` (les comparables disparus servent aussi à calibrer) |
| `url`                | Lien direct vers l'annonce comparable                                         |

## Comment Imoria choisit les comparables

- **Mêmes typologie et archétype** (appartement T2 vs. appartement T2).
- **Surface ±20 %** (un 60 m² est comparé à des 50–72 m²).
- **Proximité géographique** : mêmes commune et secteur en priorité ; élargissement progressif si le pool est trop petit.
- **Caractéristiques principales** quand renseignées : étage, DPE, présence d'un extérieur, parking.

Le score de similarité combine ces dimensions. Les comparables sont d'autant plus pertinents que la zone est dense en annonces.

## Limites

<Card href="/ressources/limites-et-couvertures#adresses-masquees-sur-les-annonces" icon="link" horizontal>
  Voir : adresses-masquees-sur-les-annonces
</Card>

- Les comparables provenant d'annonces à adresse masquée sont localisés à la commune, pas à la rue. La distance affichée peut être approximative.
- Dans une zone à faible densité d'annonces, Imoria élargit le rayon. Le score de similarité reste honnête mais les biens sont plus éloignés.
